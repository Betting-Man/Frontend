# Betting Man

포커 칩 대신 점수를 계산해 주는 베팅 보드예요. 한 기기로 돌려 쓰거나, 방 코드로 여러 기기가 접속해 쓸 수 있어요.

## 실행하기

```bash
npm install
npm run dev    # http://localhost:3000
npm test
```
